## 📖 游戏简介
一款 3D 滚球收集游戏。玩家控制小球在场景中滚动，收集所有食物得分。

## 🎯 核心功能
- **物理移动**：使用 Rigidbody + AddForce 实现平滑移动
- **收集系统**：使用 OnTriggerEnter 检测碰撞并收集食物
- **UI 系统**：使用 TextMeshPro 实时更新分数
- **摄像机跟随**：平滑跟随玩家移动

## 🕹️ 操作方式
- `W/A/S/D` 或 方向键：控制小球移动
- 滚动到食物上即可收集

## 🛠️ 技术栈
- Unity 2022.3.62f3c1
- C# 
- 物理引擎：Rigidbody
- UI：TextMeshProUGUI
